## 📂 Repository Contents

* **`ml_project_day1.ipynb`**: Jupyter Notebook containing exploratory data analysis (EDA), data cleaning, and machine learning models.
* **`ai_voice_assistant.py`**: Python script implementing an interactive voice assistant utility.
* **`student_data.csv`**: Dataset used for exploratory data analysis and visualization tasks.

* **Libraries**: Pandas, NumPy, Scikit-learn, Matplotlib
* **Environment**: Jupyter Notebook / Google Colab
